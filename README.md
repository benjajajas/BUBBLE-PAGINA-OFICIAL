# BUBBLE · Página oficial

Archivos:
- `index.html`: toda la página (HTML, CSS y JS en un solo archivo)
- `logo.jpg`: el logo del grupo

## Cómo subirla con GitHub Pages
1. Entrá a github.com y creá un repositorio nuevo (por ejemplo `bubble`), público.
2. Tocá **Add file → Upload files** y subí `index.html` y `logo.jpg`. Después **Commit changes**.
3. Andá a **Settings → Pages**.
4. En **Source** elegí **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guardá.
5. Esperá 1 o 2 minutos. Tu página queda en `https://TU-USUARIO.github.io/bubble/`.

## Para cambiar textos
Abrí `index.html` en GitHub, tocá el lápiz (Edit) y cambiá lo que quieras. Los textos de los integrantes están en la línea que empieza con `const M=`. La fecha del contador está en `const T=new Date(`.
